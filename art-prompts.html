Landlordsector picture prompts

One complete Gemini prompt for each of the 84 house pictures: 6 sizes on 14 planet types. Pick a picture in the grid, copy its prompt, and paste it into a new Gemini chat.

How to use

  1. Start a new Gemini chat for every picture. Long chats drift and copy earlier pictures.
  2. Attach nothing, except for Jungle and Water homes bigger than a shack (gold in the grid): attach the Terran picture of the same size there, because those three share one building. Every prompt writes out the art style and the camera in full, so no reference picture is needed. The box above each prompt says what to attach.
  3. One short correction if something is wrong, such as "no lamp post, no sidewalk, the ground is bare grey rock". Still wrong: a new chat with the full prompt.
  4. Save it with the file name shown above the prompt. Gemini's caption strip at the bottom does not matter; Claude cuts it off.
