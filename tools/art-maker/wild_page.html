Landlordsector wild prompts

The third picture of every home: 84 Gemini prompts, 6 sizes on 14 planet types, each a different strange idea. Same pixel-art style and size ladder as the first two pictures; the home stands in the middle and every picture has its own place, light and time of day.

How to use

  1. New Gemini chat for every picture, model 3.1 Pro, attach nothing.
  2. Save it with the file name shown above the prompt (_alt2). Do not flip it: the home stands in the middle.
  3. One short correction in the same chat if something is off; still wrong, a new chat with the full prompt.
